## 已知边界及 M3 跟进

- GET /api/servers/unread-summary 每 30 秒由 Web 轮询，被 /api/servers/{id} 捕获为 id=unread-summary，产生 400。M3 增加保留路径的独立分支，暂返回清楚的未实现 404，不伪造未读计数。未读事实属于 M4 消息域。
- Socket.IO 501 属 M2 声明边界；原阶段规划在 M4 接浏览器实时协议。M3 的 Daemon 原生 WebSocket 与其分开。
- #all/#announcement 在 DB 中真实存在，M2 无频道列表 API，侧栏显示 No channels yet。M3A 实现真实频道列表、可见性及权限，不用空数组隐藏它们。
- 初始化命令使用 Web 当前 origin（报告为 5175）。M3 必须测试原 Computer 客户端通过配置好的同源代理可达的 HTTP + /daemon/connect，或明确采用直连 Go origin 的 CLI 启动配置。不能未经原客户端/代理验证便假设这一定是前端缺陷；不修改 Web 来回避。
- 邮箱验证同 token 第二次请求 400：首次消费成功，一次性 token 正常拒绝重用，不放宽安全语义。
- 浏览器工具无法只读采集 console，本次协作者取证采用页面状态和服务器日志；不声称 console 零错误。
