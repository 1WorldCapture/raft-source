## Scope

Implement runtime id `cursor-sdk` (the legacy `cursor` CLI runtime was originally preserved and has since been retired and removed, task #5). A persistent separate Node host owns one SDKAgent and sequential Runs. Existing SDK browser login at ~/.cursor/sdk/auth.json is the already-validated main path. No billing investigation. CLI session -> key bootstrap is NOT a release dependency and remains disabled; never treat access tokens as API keys.

SDK MUST be exact @cursor/sdk@1.0.36, external original package with full lazy chunks. Node MUST be staged official v24.15.0 with checksum validation, NOT Electron process.execPath and NOT ambient PATH Node in release. Bundled SDK entry is known broken on Node: do not use or patch it. Runtime assets include node, run host, auth host, SDK production closure + platform helpers and an integrity manifest. User data outside assets. Explicit alpha is trusted-host execution, not a security sandbox.

## Cross-worker API contracts

Asset module: packages/daemon/src/cursorSdk/assets.ts
- export CURSOR_SDK_VERSION = '1.0.36', CURSOR_NODE_VERSION = '24.15.0'
- export resolveCursorSdkAssets(): { root: string; nodePath: string; runtimeEntryPath: string; authEntryPath: string; sdkVersion: string; nodeVersion: string }
- throw sanitized actionable typed errors when missing/incompatible; probe must not import SDK or use network.
- export probeCursorSdkAssets(): { available: boolean; version?: string; diagnostic?: string }
- explicit host-owner env RAFT_CURSOR_SDK_ASSETS denotes exact asset root; desktop sets from resourcesPath before importing daemon. No path selected from per-agent env.
- development default may discover packages/daemon/runtime-assets/cursor/<version>/<target> generated by asset build. Document final path.

Credential module: packages/daemon/src/runtimeAuth/cursor/credentialBroker.ts
- export resolveCursorCredentialLease(input: { slockHome: string; serverId?: string; signal?: AbortSignal }): Promise<{apiKey:string; connectionId:string; generation:number; principalId:string; backendUrl:string}>
- export detectCursorSdkModels(input?: {slockHome?:string; signal?:AbortSignal}): Promise<RuntimeModelSourceOutcome>
- existing bound connection MUST NOT silently change principal/source. First use may discover unambiguous standard SDK login; verify online using private auth host. Require numeric valid userId normalized to string; user accounts only first release. Explicit invalid key must fail closed. No raw secrets in errors/logs/argv/normal stdout/server payloads.
- public owner login/status/logout functions for Computer controls; no automatic interactive login on scan/start. Browser login uses official Cursor.auth.login in auth host with private IPC, URL only in owner callback. Borrowed source never deleted/revoked. Use cross-process lock + safe atomic owner-only storage.

Host source entries (SDK must ONLY be runtime-imported here):
- packages/daemon/src/cursorSdk/runtimeHost.ts (runtime worker)
- packages/daemon/src/cursorSdk/authHost.ts (auth worker)
Asset builder transpiles these to host/runtimeHost.mjs and host/authHost.mjs, external @cursor/sdk. Both use Node private IPC (`stdio:[ignore,pipe,pipe,ipc]`) and not stdout NDJSON for credentials. Failure output must be sanitized.

Driver: packages/daemon/src/drivers/cursor-sdk.ts, exports CursorSdkDriver and CursorSdkRuntimeSession. Driver calls resolver and broker, prepareCliTransport, managed MCP. driver.createSession returns RuntimeSession; no vendor CLI print adapter. Legacy properties persistent/direct/steer, supportsStdinNotification true. Descriptor transport child_process, lifecycle sdk_session, input request, readiness sdk_ready, turnBoundary sdk_event, postTurn keep_alive. Do not mark native standing prompt supported; use current registered prompt path without systemPrompt replacement. Current sdk user echo must never become another user message.

Runtime send(input) MUST return synchronously, accepted only after bounded local queue acceptance. It is NOT native ACK. Support optional attemptId on send; parent APM owns attempt watermarks. At most one new Run submission or pending steer, no second business inbox or auto follow-up queue in host. APM owns all follow-ups. busy readiness false/no_active_turn only when truly idle, never ACK-pending. Native run terminal+stream drained+ACK settled/unknown => exactly one Raft turn_end. `UnknownAgentError` is not not-found (SDK uses it for busy). Genuine AgentNotFoundError is distinct.

ParsedEvent addition (parent owns types.ts/APM):
{kind:'delivery_outcome'; source:'cursor_sdk'; attemptId:string; outcome:'delivered'|'deferred_to_idle'|'unknown'}
RuntimeSession.send input optional attemptId?: string. Genuine delivery_error source includes cursor_sdk_response.
Adapter must emit outcome when attemptId supplied: complete_delivered -> delivered, revert -> deferred_to_idle (no runtime error UI), ACK timeout -> unknown (not revert). Current run then suppresses further busy steering after revert until true idle. Old epoch/run/attempt results discarded. For no attemptId do not invent APM debt; existing start success path normal.

Run cancellation and shutdown are different. cancel doesn't guarantee custom callbacks finished. Stop invalidates inputs/epochs, cancel+await async disposal, deadline then process-group termination. Never say cleanup complete without proof; bound all timers and cleanup resources. Store execution has single writer/host lock; no unconditional local.force or broad catch->fresh. Re-inject model/settings/tools/MCP on resume. Keep settingSources policy explicit, preserve mandatory enterprise settings.
